# Security Policy for DateTime-TimeZone-Local-Win32

Report security issues privately, either through GitHub's private
vulnerability reporting or by email to David Pinkowitz
<dapink_cpan@pinkowitz.com>. Please don't report them in a public GitHub issue.

This policy is based on the CPAN Security Group's
[Guidelines for Adding a Security Policy to Perl Distributions](https://security.metacpan.org/docs/guides/security-policy-for-authors.html).

## How to Report a Security Vulnerability

The preferred way is GitHub's private vulnerability reporting: go to the
[Security tab](https://github.com/dapink/DateTime-TimeZone-Local-Win32/security)
of the repository and choose **Report a vulnerability**. Only you and the
maintainer can see the report.

If you can't use GitHub, email the maintainer, David Pinkowitz, at
<dapink_cpan@pinkowitz.com>.

Either way, please include the module version, your Perl and Windows versions,
and the steps needed to reproduce the problem.

The first response will be an acknowledgement, possibly with questions.

If you would like help triaging the issue, if it is being actively exploited,
or if you haven't had a response within 14 days, please copy your report to
the CPAN Security Group (CPANSec) at <cpan-security@security.metacpan.org>.

## Which Software This Policy Applies To

This policy covers DateTime::TimeZone::Local::Win32 as distributed on CPAN.

Vulnerabilities in its prerequisites (such as DateTime, DateTime::TimeZone and
Win32::TieRegistry), in Perl or in Windows are not covered, unless this module
can be used to exploit them.

## Supported Versions

Security fixes are made only for the latest release on CPAN.
